# Changelog

All notable changes to this project are listed here. Each release tag (`v0.x`) gets an entry.

## Unreleased

Everything below ships in the first tagged release, `v0.1`.

### Foundation
- Fumadocs docs site in English and Arabic, shadcn registry, CI with a physical-class guard, a block contract check and an install smoke test.
- 71 themes as installable token files (5 Mizan themes, shadcn bases and accents, tweakcn ports), with light and dark modes and an AA contrast allowlist.
- Font presets for Arabic and Latin: Geist, IBM Plex, Markazi, Noto Kufi, Readex Pro, Tajawal.

### Components
- The full shadcn set on Base UI, with right-to-left support and Phosphor icons.
- Commerce: price with the official riyal, dirham and rial signs, VAT summary, coupon input, installments, delivery estimate, payment method select, order stepper, quantity stepper, swatch select, stock indicator, wishlist button, product gallery and status badge.
- Gulf: Hijri calendar and date picker, IBAN, Saudi ID, VAT and phone inputs, region and city select, Saudi national address form, ZATCA simplified invoice with QR, opening hours and WhatsApp button.
- Inputs: file upload, tags input, multi-select, number field, time picker, password input, input mask, color picker, signature pad, inline edit, rating input and segmented control.
- Display: stat card with sparkline, QR code, copy and share buttons, announcement bar, countdown, sticky action bar, bottom nav, image lightbox, comparison slider, marquee, table of contents, cookie consent, mega menu, avatar group, timeline, back to top and tree view.
- ASCII set: box, chart, progress, spinner, text and terminal.

### Blocks
- 59 blocks with English and Arabic labels and demo data: navbars, heroes, features, logo clouds, stats, testimonials, pricing, FAQ, CTA, contact, footers, banner, legal, blog list, app shells, dashboard, data tables, settings, notifications, empty states, and login, sign-up, OTP and password-reset screens.

### Docs
- Component pages with previews and code, block pages with device frames, charts, typography, tokens, icons and a theme customizer.
