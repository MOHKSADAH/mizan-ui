description: Arabic (RTL) and English components for shadcn, built on Base UI.
---

Mizan UI is a shadcn registry. You copy each component into your project with the shadcn CLI and own the code.

- Every component works in Arabic (RTL) and English (LTR).
- Primitives come from [Base UI](https://base-ui.com).
- Icons come from [Phosphor](https://phosphoricons.com).
- Themes are token files. Components contain no theme logic.

Start with [Getting Started](./getting-started).
